# Instructions

## Migration Tracker

The `MIGRATION_TRACKER.md` file tracks the controls in `src/app/controls-to-port` that are planned for migration to the newer Angular version in this template.

When a control is finalised, update `MIGRATION_TRACKER.md` to reflect its current status (for example, mark it as `Migrated` and add any relevant notes), and update the summary counts accordingly.

## Pipe Contracts

Review `src/app/library/pipes/PIPES_CONTRACTS.md` before creating a pipe. When a pipe is added, changed, or removed, update that file with its name, location, purpose, inputs, and outputs.

## Service Contracts

Review `src/app/library/services/SERVICES_CONTRACTS.md` before creating a service. When a service is added, changed, or removed, update that file with its name, location, purpose, and public API.
